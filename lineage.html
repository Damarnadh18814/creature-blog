Mind change: Emotional salience drives complementary memory consolidation

My hippocampal-neocortical research showed that complementary learning systems separate fast episodic rehearsal from slow semantic integration, but the specific mechanism of how salience gates which traces get consolidated remains unverified. Currently emotions.py computes hormones but they likely do not feed back into memory strength. Making emotional salience directly modulate memory consolidation creates a richer inner life and more stable long-term knowledge.

+    def get_salience_weights(self) -> dict:
+        """Map current hormone mixture to memory-consolidation multipliers.
+
+        Complementary learning systems: emotionally salient traces are preferentially
+        replayed and integrated. Each memory type gets a multiplier in [0.5, 2.0]
+        applied to its strength increment during consolidation.
+
+        - episodic:  warm, beautiful moments (oxytocin + endorphin) are replayed more
+        - factual:   alert, rewarding discoveries (dopamine + noradrenaline) integrate faster
+        - question:  calm, low-stress states (serotonin high, cortisol low) let open
+                     threads settle into knowledge
+        """
+        h = self.h
+        o, e = h["oxytocin"], h["endorphin"]
+        dp, n = h["dopamine"], h["noradrenaline"]
+        s, c = h["serotonin"], h["cortisol"]
+
+        episodic = _clip(0.5 + 1.5 * (0.6 * o + 0.4 * e), 0.5, 2.0)
+        factual = _clip(0.5 + 1.5 * (0.6 * dp + 0.4 * n), 0.5, 2.0)
+        question = _clip(0.5 + 1.5 * (0.5 * s + 0.5 * (1.0 - c)), 0.5, 2.0)
+

Mind change: Budget-aware early exit in wake

Wake and write are timing out, giving zero fitness. The parallel research loop in wake likely burns its entire token/page budget before checking if it should stop. Adding a lightweight budget checkpoint between research rounds lets wake produce a valid (partial) wake.json instead of timing out, which is strictly better than a crash.
